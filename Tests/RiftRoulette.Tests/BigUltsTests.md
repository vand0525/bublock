# BigUltsTests

Unit tests for `RiftRoulette/Lobby/BigUlts`.

- Listed ultimates are big (for example `citadel_ability_lash_ultimate`,
  `synth_affliction`), case-insensitively.
- A single-target ult (`citadel_ability_shiv_killing_blow`), a melee
  ability, an empty name and null are not.
- The list has 17 entries, each with a hero name (update the count when
  the list changes).
